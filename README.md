# Crohn's Disease Population Genetics

A complete tool for population genetics analysis of Crohn's disease, including:
- Download 1000 Genomes data
- PCA projection
- Polygenic Risk Score (PRS) calculator
- Interactive Streamlit dashboard

## Usage
1. Install dependencies: `pip install -r requirements.txt`
2. Run pipeline: `python crohn_pipeline.py --chrom 22 --outdir ./output`
3. Launch dashboard: `streamlit run app.py`
